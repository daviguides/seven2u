AI integration

One Protocol, an Agno agent on Groq, a heuristic that is honest about itself

PortInsightProvidergenerate_insight(InsightContext) -> SeriesInsight. Context = series, episode?, totals, watched, notes.
PrimaryGroqProvider (Agno)Agent(model=Groq("qwen/qwen3.8-27b"), instructions=…), asyncio.wait_for(arun, 2.5s). Spoiler-free critic, ≤120 words, delimited untrusted data.
FallbackHeuristicTemplateProviderSynopsis excerpt + genre tone (25 genres) + rating signal + progress phase + note count. Used on timeout, error, empty text, or no key.
Policy
Fail fast
No retry, no circuit breaker. Any failure → fallback in the same request. Never a 5xx.
Contract
source field
UI shows AI badge for llm:groq, smart summary + muted note for heuristic:fallback.

What's running

Verified on Docker, not on paper

  • Cold start. DB retry loop observed (attempt 1 failed, attempt 2 ready), tables created, app on 7777.
  • Live TVMaze. "breaking" → 10 results; /series/169 → 5 seasons, 62 episodes, HTML stripped.
  • Persistence. Watched toggle survived docker compose restart app. Series and episode notes stored separately; blank note → 422.
  • AI. No key → heuristic:fallback reflecting progress and note count. With GROQ_API_KEY → llm:groq via Agno + qwen3.8-27b.
  • UI. Browser-checked at desktop and 390px: search grid, detail, accordion, optimistic toggle, zero console errors.
  • Bugs found by running it. asyncio.gather over a shared AsyncSession (Postgres-only, SQLite masked it); duplicate native clear button. Both fixed and committed.
